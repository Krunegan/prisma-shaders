PRISMA 1.0.0 — Windows
=======================

Shader packs for Luanti.

Requirements
------------
* 64-bit Windows 10 or later.
* Luanti 5.17 for Windows.
* OpenGL 3.2 or later. Compute passes require OpenGL 4.3.

Installation
------------
1. Extract the archive to a writable directory.
2. Open prisma.exe and select luanti.exe from Luanti's bin directory.
3. Prisma includes no packs: install one on "Download packs", select it and
   choose Play.

In-game controls
----------------
* Home: open or close the Prisma menu.
* End: enable or disable the active pack.

Documentation
-------------
docs/usage.md          using Prisma: packs, settings (prisma.ini), command line
docs/how-it-works.md   how Prisma works
docs/shaderpacks.md    writing shader packs

Logs are written under logs/ beside prisma.exe. See prisma.log for pack and
shader errors.
